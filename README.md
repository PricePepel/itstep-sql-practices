# itstep-sql-practices

SQL practice work from ITSTEP lessons, using SQLite and DB Browser for SQLite.

Each `lesson*` or `lsn*` folder holds one lesson's scripts: table creation, inserts, filters, queries and homework. The `.db` files are the matching databases, and the `.sqbpro` files open as DB Browser projects.

To try one, open a `.sqbpro` file in [DB Browser for SQLite](https://sqlitebrowser.org/), or run a script against its database:

```bash
sqlite3 lesson2/lesson2.db < lesson2/lesson2.sql
```
